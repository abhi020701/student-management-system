# Student Management System

A Java Full Stack web application built using Servlets, JSP, JDBC, and MySQL to manage student records with authentication and CRUD operations.

## Features
- Admin login system
- Add, edit, delete, and view students
- MySQL database integration
- MVC architecture
- JSP-based UI

## Technologies Used
- Java
- Servlets
- JSP
- JDBC
- MySQL
- HTML, CSS

## Setup Instructions
1. Clone the repository:
git clone https://github.com/abhi020701/student-management-system
2. Import project into Eclipse / IntelliJ as Dynamic Web Project
3. Configure Apache Tomcat server
4. Run SQL script in MySQL
5. Update DB credentials in `DBConnection.java`
6. Deploy and run
